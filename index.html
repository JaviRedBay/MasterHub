    Sincronización Google Drive (Nube)
    Compatible con Firefox y Móvil
    Pasos para obtener tu Client ID en Google Cloud (Gratuito):
    1. Accede a la consola de desarrollador: Google Cloud Console → Credenciales.
    2. Crea un proyecto nuevo (por ejemplo: "DnD Master Hub") o selecciona uno existente.
    3. En el menú lateral, entra en Pantalla de consentimiento de OAuth → Elige tipo "Externo" → Asigna un nombre a la app y tu correo.
    4. En el menú lateral, ve a APIs y servicios → Biblioteca, busca Google Drive API y haz clic en HABILITAR.
    5. En Credenciales, pulsa + Crear credenciales → ID de cliente de OAuth.
    6. En Tipo de aplicación elige "Aplicación web".
    7. En Orígenes autorizados de JavaScript añade la URL exacta donde abres la app (ejemplo: http://localhost:8080 o http://127.0.0.1:5500 o tu dominio web).
    8. Haz clic en Crear y copia el ID de cliente resultante (terminado en .apps.googleusercontent.com).
    9. Importante para evitar Error 403 (access_denied): Ve a Pantalla de consentimiento de OAuth → Usuarios de prueba y añade tu propia cuenta de correo de Gmail con la que vas a iniciar sesión.
    Nota: Solo necesitas hacer esto una vez; la web recordará tu Client ID en futuras sesiones.
